# 使用说明
在大多数可编辑区域中，选中文字并等待约 1 秒，会自动弹出纠错后的内容及对应的中文翻译（受系统限制，选中自动纠错功能仅在部分编辑区域可用）。你也可以在任意位置复制内容（如常用的 Ctrl+C 或右键复制），等待约 1 秒后同样会自动弹出语法纠错。
弹出窗口会在你点击鼠标或 10 秒无操作后自动消失；当鼠标移入窗口时，它会保持显示，不会消失。弹出效果详见截图。

# 关于隐私
建议在 Settings 设置中配置你自己的大模型，任意 OpenAI 兼容模型均可，例如 Ollama、豆包、DeepSeek。

服务器端仅用于登录，不保存任何客户端对话数据。但你的输入内容会发送给大模型（LLM）进行处理，请务必注意保护个人隐私。当你使用自己的大模型时，数据将直接传输给该模型，不会经过服务器端。
